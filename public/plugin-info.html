🔗 TopLocs Link Plugin

Share and organize links within TopLocs spheres

Federated Architecture

About

The Link Plugin enables users to share and organize links within TopLocs spheres. It features a modern decoupled architecture with separate development and plugin environments, using Module Federation for dynamic loading.

📎 Link Sharing

Share URLs with title, description, and automatic metadata extraction

🏷️ Organization

Categorize links with tags and collections for easy discovery

🔄 Real-time Sync

P2P synchronization using Gun.js for instant updates

🎨 Modern UI

Clean, responsive interface with Vue 3 and Tailwind CSS

Architecture

The Link Plugin showcases the modern TopLocs plugin architecture:

  • Federated Plugin: Uses Module Federation for dynamic loading
  • SDK Integration: Built with @toplocs/plugin-sdk
  • P2P Ready: Gun.js integration for decentralized data
  • Development Mode: Separate dev environment with hot-reload

Integration

To use this plugin in your TopLocs instance, add it to your plugin configuration:

{ "id": "link_plugin", "name": "Link", "url": "https://toplocs.github.io/link-plugin/assets/plugin.js", "version": "1.0.0", "description": "Share and organize links within TopLocs spheres", "author": "TopLocs Team" }

The plugin exposes components for the following slots:

  • Info/Sidebar - Link list sidebar widget
  • Settings/Content - Link plugin settings

Plugin Endpoints

The plugin is served via GitHub Pages with the following key endpoints:

  • Plugin Entry: https://toplocs.github.io/link-plugin/assets/plugin.js
  • Landing Page: https://toplocs.github.io/link-plugin/
  • Live Demo: Available at the landing page URL

Development

The Link Plugin is built with:

  • Vue 3 + TypeScript
  • Vite + Module Federation
  • @toplocs/plugin-sdk for plugin development
  • Gun.js for P2P data synchronization
  • Tailwind CSS for styling

To run locally:

# Clone the repository git clone https://github.com/toplocs/link-plugin.git cd link-plugin # Install dependencies pnpm install # Run development server pnpm dev # Build for production pnpm build # Preview built plugin pnpm preview

Development URLs:

  • Dev Environment: http://localhost:4173
  • Plugin Server: http://localhost:3006
